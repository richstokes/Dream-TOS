# Sample artwork

Generated with the built-in imagegen tool on 2026-09-28 for this project.
No commercial game sprites, maps or audio were extracted. The hedgehog
picture is fan art; Sonic and related character rights belong to Sega.
The project claims no exclusive copyright in AI-generated sample pixels.
Neither sample is used as a game asset in the open-source game bundle.

Originals: `hedgehog-original.png`, `space-original.png`.
Disc copies: `disc/SONIC.PNG`, `disc/SPACE.PNG`, 320×240 PNG.
Only technical downsampling was applied, with macOS `sips -z 240 320`.
Building the port uses the checked-in disc files; imagegen and sips are not
build dependencies.
