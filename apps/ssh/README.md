# Native SSH client

GPL-3.0-or-later. See ../../docs/SSH.md for user setup and limitations.

`platform_dc.c` is the only Dreamcast-specific layer. It uses the existing
optional native network API, GEMDOS drive files and raw console output.
`tests/ssh_platform_host.c` swaps in POSIX files/console but uses the same
`src/dreamcast/hal_tcp.c` adapter. `scripts/ssh-sources.sh` defines identical
library configuration/source lists for both builds. The native build is
`scripts/build-bundle.sh --ssh-only`; the full bundle invokes it normally.

Libraries are pinned in ../vendor/sources.json. wolfCrypt is configured for
portable C, single-threaded use, SHA-2, modern curves and constant-time ECC/
blinded RSA, without TLS, assembly or the SDK RNG. SP math is limited to
4096-bit RSA. The seed callback uses wolfCrypt Hash_DRBG, initialized from a
private 512-bit OS-generated seed when available. Next-run state is persisted
first. If seed validation or rotation fails, the user can explicitly type
`risk` to allow weak randomness for that connection. This fallback hashes
public RTC/timing samples with SHA-512 before initializing Hash_DRBG; hashing
does not make those samples secure. It never writes a seed file. The prompt
defaults to cancellation and precedes DNS, TCP and authentication. Host-key
pinning remains mandatory in both modes. Master DRBG reseeding fails closed if
its built-in request limit is exhausted; start a new connection to reinitialize.

Two explicitly conditional wolfSSH changes in src/internal.c:

- WOLFSSH_DC_TERMINAL supplies TERM=xterm and the actual 80x30 / 640x480 PTY.
- WOLFSSH_CLIENT_AUTH_SELECT calls ssh_choose_auth after parsing an auth-failure
  method list. This preserves upstream protocol handling while letting the
  client prefer a supplied key and handle partial multi-factor authentication.

libvterm's two encoding/*.inc tables were generated by the upstream
`tbl2inc_c.pl` from the included .tbl files. No parser changes are applied.
The bcrypt_pbkdf.c and blowfish.c files are unchanged libssh2 1.11.1 sources;
libssh2_priv.h supplies their SHA-512/wipe compatibility interface. Identity
parsing is bounded to one key and 32 KiB; decrypted OpenSSH data is wrapped in
an unencrypted OpenSSH container for upstream signing. Secret buffers are
wiped on release. Terminal escapes from the server are interpreted by libvterm,
never forwarded to the OS console; only locally generated VT52 drawing is sent.

No real credentials, reusable random seeds, or host-private keys belong in
this repository. Test identities are generated in temporary/ignored folders.
