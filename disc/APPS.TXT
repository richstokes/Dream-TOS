NATIVE DREAMCAST APPLICATION BUNDLE
==================================
All programs are native SH-4 code. Atari 68000 executables cannot run.
Open a .PRG in EmuDesk to start it. Save on C:, the temporary RAM disk.
D: is read-only. Reset or power-off erases C:, including all saved work.

PROGRAM FOLDERS ON D:
APPS: EDITOR, IMAGES, PAINT, MP3
GAMES: FIFTEEN, MINES, NET, WORM, BLOCKS
UTILS: FTP, VMUEDIT, SDFORMAT, SYSINFO, BENCH, HELLO, VDITEST, RUNTIME,
       all .TTP tools
BENCH.DAT lives in UTILS beside BENCH.PRG. All program folders are on PATH.
Startup .ACC files, guides, samples and licenses remain at the disc root.

CLOCK.ACC - resident GEM clock desk accessory
Loaded automatically at boot. Choose Desk > Clock to open or raise it.
Analogue face, 24-hour digital time and date from the console clock.
GEMDOS time advances in two-second steps. The desktop stays usable.
Close box or Esc hides; Desk > Clock reopens. Drag to move or resize,
or use Ctrl+arrows / Ctrl+Shift+arrows. Program transitions hide the
window; the accessory remains loaded. Do not launch .ACC as a .PRG.

CONTROL.ACC - Dreamcast Control Panel, Desk > DC Control
Mouse speed, key repeat delay/interval and desktop colour.
Tab selects a row; Left/Right adjusts; D restores defaults.
Live mouse, keyboard and controller diagnostics. Select a Settings VMU;
S saves, L loads, D applies defaults (S saves them). Uses two VMU blocks with an icon.
The first valid settings save loads at boot. Unsaved changes last until reset.
Mouse speed changes physical Maple mouse movement, not Alt+arrow movement.

MONITOR.ACC - System Monitor, Desk > System Monitor
Uptime, GEM free memory/history, KOS heap, C:/D: space and Maple devices.
R refreshes; Space pauses/resumes; Up/Down scrolls devices.

VMUTOOL.ACC - VMU Toolbox (READ ONLY), Desk > VMU Toolbox
Lists connected cards, free blocks, files, timestamps and copy flags.
Left/Right changes cards; Up/Down selects files; PgUp/PgDn moves 8 files.
R refreshes. Connect a card then press R. Reads metadata only.
No format, delete, write, restore, LCD changes or file-content operations.
Supports standard 128 KiB VMU metadata; other layouts may be unsupported.

VMUEDIT.PRG - VMU Editor (open from EmuDesk; fullscreen)
Files: I import a file from C:/D:/SD onto the VMU, E export it as a raw file,
N rename, D delete (all ask first), R refresh, Left/Right card, Esc quit.
L opens the 48x32 LCD editor: mouse left draws / right erases, arrows+Space,
I invert C clear H/V flip Z undo, T live push to the VMU screen, L/S load or
save a 1-bit BMP. C opens the icon editor for a VMS save (paint the 32x32
icon, edit its 16 colours, S writes back). Never formats; refuses damaged
cards, games and copy-protected files. Hardware-untested: see ACCESSORIES.md.

All accessories: close box or Esc hides. Reopen from Desk.
Ctrl+arrows moves; Ctrl+Shift+arrows resizes. Program transitions hide
windows; the accessories remain resident. Do not double-click .ACC files.

SDFORMAT.PRG - graphical FAT16 SD card formatter (in D:\UTILS)
Insert the serial-port SD adapter and card before booting. F starts;
confirm Erase SD to erase ALL files and partitions on that physical card.
C: and D: are protected and cannot be formatted. Uses up to 2 GiB in one
FAT16 partition (E:), leaving the rest unused. Minimum card size: 4 MiB.
Close SD files first. Keep power on and the card inserted until finished.
Remounts when safe; otherwise prompts for a reboot before using the card.
Esc quits when idle. Quick format does not securely erase file contents.

FTP.PRG - graphical anonymous FTP server
Choose C: RAM, D: Disc, or a mounted E:-H: SD drive (SD preferred).
Click a folder then Open, or use Up/Down and Return. U goes to parent;
</> or PgUp/PgDn pages. S starts sharing the displayed folder on port 21.
Connect to the shown address using plain FTP, anonymous, passive mode,
binary transfers, one connection. No password is checked. C:/SD allow
uploads, overwrite, delete and rename; D: is read-only. Use DOS 8.3 names.
S stops; Esc or close quits. Keep this app open while transferring.
Interrupted uploads may leave partial files. C: is erased at reset.
Native networking requires disc/GDEMU boot, not dcload-ip.

EDITOR.PRG - Kilo plain-text editor
Ctrl+O open; Ctrl+N new; Ctrl+S save; Ctrl+A save as; Ctrl+F search;
Ctrl+Q quit. Arrow/Home/End keys move. Limit: 64 KiB / 1023 lines.
Use DOS 8.3 filenames, for example C:\NOTES.TXT. No rich text or undo.

IMAGES.PRG - PNG, JPEG and BMP viewer using stb_image
N next sample; O open; G greyscale; M mirror; S export BMP; Esc exit.
Bundled samples: SONIC.PNG (generated fan art) and SPACE.PNG.
Maximum image: 640x480; encoded file: 1 MiB. Display/export: 16 colours.

PAINT.PRG - 16-colour paint program
Mouse or keyboard. P pen B brush X eraser L line R rect F filled rect
E ellipse K filled ellipse G fill I picker H pan; 0-9 !@#$%^ colours; U undo
Y redo C clear; + - size; Tab swap colours; arrows + Space/Return draw.
Ctrl+N new, Ctrl+O open, Ctrl+S save, Ctrl+A save as (BMP; SD drive if
present, else C:). Opens IMAGES exports. ? shows help; Esc quits.

CALC.ACC - scientific calculator using tinyexpr
Desk > Calculator opens the resident accessory beside other windows.
Close or Esc hides it, keeping the expression and answer for next time.
Program switches hide its window too; reopen it from Desk when available.
Click the keypad or type expressions. Return or = evaluates.
Tab selects keypad; arrows move; Space presses a button. Typing edits.
Left/Right/Home/End move the caret; Backspace/Delete edit the expression.
AC or Ctrl+U clears all; DEL backspaces; +/- changes the expression sign.
After =, an operator continues with ans; digits start a new calculation.
Close function parentheses with ). Try sqrt(144)+2^3 or ans*2.
Trig uses radians. ^ is left associative. Display: 12 significant digits.
Drag the title bar to move; drag the lower-right gadget to resize.
F5 or the upper-right gadget toggles full size and the previous size.
Ctrl+arrows moves; Ctrl+Shift+arrows resizes. The keypad adapts to window size.
Fullscreen apps can block accessory access; foreground PRGs remain single-tasking.

WORM.PRG - Jeffrey Armstrong's Atari GEM Worm
P starts/pauses; arrows or WASD steer; N new; H scores; Esc exits.
Eat green food, avoid walls and your tail. Scores: C:\WORM.HI.

BLOCKS.PRG - falling-block game
Arrows move; Up/X turn right; Z turn left; Down soft drop; Space hard drop;
C hold; P pause; Esc menu. Pad: D-pad, A/B turn, X hold, Up/Y drop, Start pause.
Top-5 scores: BLOCKS.HI on the SD card if present, else C:.

FIFTEEN.PRG - Simon Tatham's sliding-tile puzzle
Arrow keys slide tiles into the gap. Arrange numbers in order.

MINES.PRG - Simon Tatham's Mines
Arrows move the cursor; Space reveals; F flags a square.
Reveal all safe squares while avoiding mines.

NET.PRG - Simon Tatham's network puzzle
Arrows move the cursor; Space rotates; F locks a tile.
Connect all the wires to the central power source.

All three puzzles: N new, U undo, R redo, S save, L load, H help,
Esc exit. Saves are C:\FIFTEEN.SAV, C:\MINES.SAV and C:\NET.SAV.
Mouse controls are also supported by the puzzle games.

BENCH.PRG - native CPU, memory, VDI and file benchmark
R or Return runs; Esc cancels while running or exits when idle.
S saves C:\BENCH.TXT; E cycles Unspecified / Real hardware / Flycast.
Three samples per test; median and range. BENCH.DAT is its read-test input.
C: tests use a temporary RAM file. D: reads include cache effects.
Flycast scores are not physical Dreamcast measurements.

MP3.PRG - MP3 and WAV player with file browser and visualiser
Pick a drive (E:-H: SD card, C:, D:) and folder; Return or double-click plays.
Space play/pause, Left/Right seek 10 s, N/P next/previous, +/- volume,
S stop, R repeat, D next drive, Backspace parent folder, Esc quit.
Also mouse: transport buttons, progress bar, volume bar, file list.
MP3 (any bitrate, 8-48 kHz, VBR) and 8/16-bit PCM WAV. Shows ID3 tags.
The status line shows measured decode load. Files use 8.3 names.
Needs the audio-capable OS build; see docs/AUDIO.md.

RUNTIME.PRG tests native allocation, stdio, file access and math.
VDITEST.PRG checks graphics. HELLO.PRG is the minimal ABI example.
SYSINFO.PRG (when included) reports live Dreamcast/OS/device information.
